Set Keypad Code

Keypad codes are 4 digits and can be set up as one of four types:
1) 24/7 Code (always valid)
2) 24/7 Temporary Code (valid for a specified number of days)
3) Day & Time Limited Code
4) Day & Time Limited Temporary Code (valid for a specified number of days)
Only numeric characters (0-9) are allowed.

This code must be exactly 4 digits (0-9).
